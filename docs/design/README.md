# Design history

One folder per feature: a README with what was agreed, sketches (`.html`, open in a browser)
and screenshots from the Karoo 3 (`device/`). Newest work first.

| Folder | Feature |
| --- | --- |
| `header-everywhere/` | Karoo header (icon + field name) in every look |
| `karoo-type/` | Karoo's light number font tried, kept 0.1.4 (clearer); every variant at half page |
| `bigger-pulse/` | Bigger pulse line in the text colour, taller zone bars (before and after) |
| `looks/` | Round 3: BigWatts or Karoo look, number and background as separate settings, one-row field (mockup) |
| `transparent-field/` | Bug fix: no background of our own, so the Karoo's rounded tile and border show (device shots before and after) |
| `scope/` | What Big Watts is: one field, five styles coloured by Karoo power zones, Settings page |
